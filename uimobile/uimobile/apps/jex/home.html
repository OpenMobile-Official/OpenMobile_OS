Wiby Search Guide

Wiby.me is a search engine for discovering hand-coded, retro-style websites.

If your browser can't use the search bar:

  1. Visit wiby.me
  2. Scroll down and click “Surprise Me” to explore random retro sites.
  3. Repeat to discover more hidden gems.

Custom Wiby Search (without search bar):

Use this format in your browser's address bar:
https://wiby.me/?q=your+search+terms
Replace your+search+terms with keywords (use + instead of spaces).
Example: https://wiby.me/?q=retro+computingretro computing search

Cool Features of Jex Web Browser
